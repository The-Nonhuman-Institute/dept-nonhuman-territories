Is the native system self-consistent?

The system's documented categories (33 labels) vastly exceed the author's formal system definition (8 categories). The filed categories introduce many variants (e.g., emergent_descendant_compact, emergent_descendant_incipient, emergent_neonate_compact, emergent_mid_compact, active_accumulator, descendant_incipient) that have no corresponding formal definitions. This suggests either incomplete documentation or real-time category proliferation. The system is fundamentally non-hierarchical and trait-based; conventional tier mapping is inherently lossy.
